# Chrome 웹 스토어 Release Candidate

목표: 1.0.0. 현재 manifest 0.1.0 유지. 아래 Chrome QA와 사용자 승인이 끝나기 전에는 정식 출시 또는 버전 확정을 하지 않습니다.

## 자동 검사와 범위

`npm test`, `npm run lint`, `npm run build`, `npm run release:package`, `git diff --check`를 실행합니다. 테스트는 모의 Chrome API를 사용하며 실제 브라우저 테스트가 아닙니다. 패키저는 명시적 허용 목록으로 manifest·패널·worker·사용 아이콘만 포함하며 PNG 치수, 권한, 루트 manifest, ZIP 항목과 SHA-256을 검사합니다. 원본 고해상도 PNG 및 macOS ICNS는 저장소에 보존하고 제출 ZIP에서 제외합니다.

## 실제 Chrome QA — 모두 미실행

기존 사용자 데이터를 건드리지 않도록 별도 Chrome 테스트 프로필에서 ZIP을 풀어 `chrome://extensions` → 개발자 모드 → 압축해제된 확장 프로그램 로드로 설치합니다. 웹 localhost 미리보기는 Chrome API 검증 대상이 아닙니다. 각 항목에 Chrome 버전·OS·패키지 SHA·관찰 결과·스크린샷을 기록하세요.

- [ ] 도구 모음 클릭으로 패널 열기, worker 오류 없음. 공식 오비탈 로고와 아이콘 확인. 좁은 패널에서 메뉴·모달·긴 이름 UI 확인.
- [ ] Workspace 생성: 이름·모든 아이콘·모든 색상 저장. 공백 이름 차단, 40자 제한 확인.
- [ ] 이름·아이콘·색상 편집, 순서 이동, 접기·펼치기 후 패널 재실행하여 유지 확인.
- [ ] Workspace 삭제 취소는 아무 변화 없음. 연결 없는 Workspace 삭제는 다른 기록 유지.
- [ ] 실제 그룹 이름·색상·탭 수 표시. 펼친 탭 클릭은 기존 탭 활성화, 새 탭 생성 없음.
- [ ] 기존 그룹 배정·재배정·연결 제거 확인. 저장 UUID 분류와 Unassigned 표시 확인.
- [ ] 선택한 미그룹 탭만 새 그룹으로 생성. 다른 그룹이나 일반 탭 보존.
- [ ] 기존 그룹 연결 기본값은 원래 색상 유지. Follow Workspace 선택 후 보라→purple, 분홍→pink 등 다른 색상 적용. 편집·재배정·Keep Chrome 전환 확인.
- [ ] Unassigned 및 Workspace 그룹 ··· → Ungroup. 그룹 표시는 Chrome와 패널에서 제거되고 모든 웹사이트 탭은 유지. 저장 Workspace와 다른 그룹 보존.
- [ ] 여러 창에 연결된 Workspace 삭제. 확인문구 확인, 모든 연결 그룹 해제, 탭 ID·URL·개수 유지, 다른 Workspace/일반 탭 불변. local 연결 정리 확인.
- [ ] Chrome에서 생성·수정·일부 탭 이동·전체 해제·탭 닫기·창 이동 후 패널 자동 반영. 유령 그룹 없음.
- [ ] 개발자 도구 또는 테스트 fixture로 API/저장 실패 재현. 오류 표시, 실패한 그룹 임의 제거 없음, 삭제 실패 시 Workspace 유지, 재시도 가능.
- [ ] 테스트 프로필의 시작 설정을 이전 세션 복원으로 지정. Chrome 완전 종료·재시작 후 Workspace CRUD 설정과 가능한 그룹 분류 유지. 일시 ID 재사용으로 다른 그룹 배정되지 않음.
- [ ] 복원하지 않는 세션·실제 그룹 없는 상태에서는 저장 링크만으로 활성 그룹 카드 생성 안 됨. 동일 지문 중복·재시작 전 URL 변경의 분류 한계 확인.
- [ ] 확장 프로그램 reload 후 local 유지, session 재연결, 이벤트 리스너 중복 없음.
- [ ] Network 패널로 favicon 외 원격 전송·분석 호출 없음 확인. 정책 초안과 일치 확인.

## 출시 차단 조건

수동 체크가 하나라도 미완료/실패하면 1.0.0 미확정. 현재 PR #6→#7→#9→#10→#12→#14→#16→#18에 의존하는 누적 RC이며 main의 출시 빌드가 아닙니다. 사용자 승인 후 순서대로 통합하고 최종 main에서 모든 검사·ZIP을 재생성해야 합니다. Chrome 웹 스토어 승인 및 배포는 별도 작업입니다.

저장 데이터 흐름과 권한 사유는 [개인정보 초안](privacy-policy-draft.md), [스토어 초안](store-listing-draft.md)에 기록했습니다. 해시를 익명 데이터로 간주하지 않으며 favicon 원격 요청 가능성을 포함합니다.
