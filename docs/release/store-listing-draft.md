# 스토어 소개 및 제출 정보 초안

이름: SKOPE — Workspace Manager

짧은 소개: Chrome 탭 그룹을 Workspace로 분류하고 사이드 패널에서 관리하세요.

## 상세 소개

SKOPE는 Chrome의 실제 탭 그룹을 나만의 Workspace로 정리하는 확장 프로그램입니다.

- Workspace 생성·편집·삭제, 아이콘과 색상 설정, 접기·펼치기 및 순서 변경
- 현재 창의 Chrome 그룹과 내부 탭 목록 표시, 기존 탭으로 이동
- 기존 그룹 연결 또는 선택한 미그룹 탭으로 새 그룹 생성
- Workspace 색상 따라가기 또는 기존 Chrome 그룹 색상 유지
- 그룹 메뉴에서 그룹화 해제: 열린 웹사이트 탭은 그대로 유지
- Workspace 삭제 시 여러 창에 연결된 활성 그룹의 그룹화 해제
- 기기 내 저장소에 Workspace 설정 저장

Workspace 기록은 탭 전체 백업이 아닙니다. 닫힌 탭이나 삭제된 그룹을 복원하는 기능은 현재 제공하지 않습니다. Chrome 색상은 지원되는 기본 색상으로 매핑됩니다. 재시작 후 연결은 실제 그룹과 저장 지문이 일치하는 경우에만 복원하며, 내용을 바꾼 뒤 저장되지 않았거나 동일한 지문의 그룹이 중복되면 재배정이 필요할 수 있습니다.

계정이나 SKOPE 서버 없이 사용합니다. favicon 표시 과정에서는 해당 사이트로 이미지 요청이 발생할 수 있습니다.

## 단일 목적 및 권한 사유

단일 목적: Chrome의 실제 탭 그룹을 로컬 Workspace로 분류하고 사이드 패널에서 관리합니다.

| 권한 | 실제 사용 목적 |
| --- | --- |
| sidePanel | 도구 모음 클릭으로 Workspace 관리 패널 열기 |
| storage | Workspace·그룹 연결 기록은 local, 임시 그룹 식별 매핑은 session 저장 |
| tabGroups | 그룹 조회, 변경 이벤트, 사용자 선택에 따른 그룹 제목·색상 설정 |
| tabs | 제목·URL·favicon 읽기, 연결 지문 계산, 기존 탭 활성화, 선택 탭 그룹화와 해제 |

`tabs`는 민감한 탭 속성을 읽는 데 필요합니다. 한 번 선택한 탭만 허용하는 activeTab으로는 창의 모든 그룹 표시 및 다른 창의 연결 그룹 삭제 정책을 충족하지 못합니다. host permissions, content scripts, cookies, history, webRequest, unlimitedStorage는 요청하지 않습니다.

개인정보 대시보드에는 URL·제목 처리를 웹 방문 기록 관련 정보로 정확히 공개하고, 로컬 해시 저장 및 favicon 네트워크 동작을 설명해야 합니다. 원격 실행 코드 없음, 판매·광고·신용평가 이용 없음에 대한 확인은 제출 담당자가 정책 초안과 실제 패키지에 맞춰 수행합니다.

## 제출 전 미완료 항목

- 공개 개인정보 처리방침 URL, 운영 주체·문의 연락처·시행일
- 실제 Chrome 스크린샷 및 스토어 요구 크기에 맞는 소개 이미지
- 개발자 계정 및 개인정보 대시보드 작성·검토
- Chrome 수동 QA 승인, 의존 PR 승인·통합, 최종 버전 확정

자동 업로드·배포하지 않습니다. [공식 개인정보 입력 안내](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy/)에 따라 제출 시점에 다시 검토하세요.
