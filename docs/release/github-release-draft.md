# GitHub Release 설명문 초안 — SKOPE Extension v1.0.0

**게시 보류:** 목표 1.0.0은 아직 확정하지 않았습니다. 현재 후보 ZIP의 manifest는 0.1.0입니다. 이 파일명으로 최종 릴리스를 게시하기 전에 수동 QA·사용자 승인 후 manifest/package 버전과 릴리스 태그를 일치시키고 ZIP을 재생성해야 합니다. 독립형 Browser는 배포하지 않습니다.

## 포함된 변경사항

- Workspace 생성·편집·삭제, 아이콘·색상·순서·접힘 설정 및 로컬 저장
- Chrome 실제 그룹과 탭 목록 표시, 그룹 배정·재배정 및 기존 탭 활성화
- 선택한 미그룹 탭으로 그룹 생성, Workspace 색상 따라가기 또는 Chrome 색상 유지
- 그룹 메뉴 Ungroup과 Workspace 삭제 시 여러 창의 연결 그룹 해제. 웹사이트 탭을 닫는 코드는 포함하지 않음
- 그룹 변경 이벤트 동기화와 오래된 조회 결과 차단, 삭제 실패 시 저장 기록 보존
- 공식 오비탈 로고와 Manifest V3 Side Panel

## 검증 상태와 알려진 제한

자동 검사는 모의 Chrome API에 기반하며 실제 Chrome 동작을 보장하지 않습니다. [RC 수동 체크리스트](rc-checklist.md)의 설치·CRUD·해제·다중 창 삭제·재시작과 아래 업데이트 검증은 미완료입니다.

Workspace 기록은 열린 탭 전체 백업이 아니며 닫힌 탭 복원 기능은 없습니다. 그룹 목록은 현재 창 기준입니다. 재시작/업데이트 후 그룹 ID는 재사용하지 않고 지문으로 연결을 판단하므로 내용이 바뀌거나 동일 지문이 중복되면 재배정이 필요할 수 있습니다. Chrome 색상은 지원되는 기본 색상으로 매핑됩니다. favicon에 원격 요청이 발생할 수 있습니다.

## 설치와 업데이트

[README 사용자 안내](../../README.md#일반-사용자-설치-github-releases)에 따라 ZIP을 풀어 개발자 모드에서 설치하세요. 업데이트는 같은 Chrome 프로필과 기존 설치 경로를 유지하고 확장 프로그램을 제거하지 않는 방식으로 수행합니다. 자동 업데이트는 제공하지 않습니다.

첨부 예정: `SKOPE-Extension-v1.0.0.zip`, 해당 `.sha256`, 검증 결과. 현재 파일은 내부 QA용 후보이며 공개 배포 승인 전입니다.
